# 0. 한 문장 결론
"계획은 세웠는데 시작이 안 된다면, 그 다음은 우리가 합니다. 착수·유지·복귀에 집중한 실행 보조 앱 — 진단 여부에 관계없이 ADHD 특성을 가진 모든 성인이 사용할 수 있다."

## 1-2. 핵심 전략

## 2-3. 2차 타깃 — ADHD 의심·미진단 성인
•  할 일을 시작하는 데 20분 이상 걸리는 경우가 잦다
•  집중하다가 갑자기 딴 생각에 빠져드는 빈도가 높다
•  중간에 끊기면 다시 시작하기가 어렵다
•  여러 작업을 전환할 때 예상보다 훨씬 오래 걸린다
•  기분이나 의욕이 생산성에 큰 영향을 준다

# 4. 신경과학적 원인 구조
① 도파민/노르에피네프린 불균형
•  즉각적 보상이 없는 과제에 대한 동기 생성이 어렵다 → 착수 지연
•  외부 자극 억제 기능이 약해 주의가 쉽게 이탈한다
•  감정 조절과 실행 계획 기능이 동시에 저하된다
② 전두엽-기저핵 회로 결함
•  진행 중인 과제의 맥락 정보를 유지하기 어렵다 → 방해 후 복귀 실패
•  과제 전환 시 전환 비용이 크다
•  복잡한 과제를 단계로 분해하는 데 추가 인지 자원이 필요하다
③ 시간 지각 왜곡 (Time Blindness)
•  작업에 얼마나 시간이 걸릴지 예측이 어렵다
•  데드라인이 멀리 느껴져 착수를 계속 미루게 된다
•  타이머와 외부 시간 구조가 내부 시간 감각을 대체한다
핵심 통찰: ADHD 뇌는 '할 수 없는' 것이 아니라 '지금 당장 흥미롭거나 보상이 있는 것만 할 수 있는' 뇌다. Own Ur Time은 외부 구조(External Scaffolding)로 실행기능을 대신 담당한다.

# 6. 성취 표시 & 보상 설계
## 6-1. 성취 표시 원칙
"얼마나 못했나"는 절대 보여주지 않는다. "얼마나 했나"만 다양한 방식으로 보여준다.
•  히트맵 빈 날은 그냥 비워둔다 — 회색 또는 '0'으로 채우지 않는다
•  '7일 연속 스트릭' 대신 '최근 7일 중 5일 활동'으로 표현한다
•  비교 기준은 어제의 나로만 한정한다
•  통계는 사용자가 보고 싶을 때 진입 — 메인 화면에 미달성 수치 노출 금지
## 6-2. 보상 레이어 3단계
## 6-3. 레이어 2 조건 보상 상세
핵심 원칙: '오늘 10개 완료'보다 '컨디션 나쁜 날 1번 시작'에 더 희귀한 보상이 나와야 한다.
# 7. 온보딩 & 로그인
로그인 = 착수 장벽. 초기 이탈률 상승의 주요 원인이다. 로그인은 사용자가 앱의 가치를 경험한 이후에 요청한다.
# 8. 동반질환 보조 기능

# 9. 캘린더 연동 전략
## 9-1. 원칙
읽기 전용으로만 연동한다. 일정 목록을 앱 안에 그대로 보여주거나 캘린더에 새 일정을 생성·수정하지 않는다. Own Ur Time은 일정 관리 앱이 아니다.
## 9-2. 제공 기능
① 업무 시작/종료 인식
•  업무 시간 시작 → '지금 업무 시간이에요, 시작할까요?' 착수 트리거 알림
•  업무 시간 종료 → '오늘 일정이 끝났어요, 마무리할까요?' 마감 알림
•  일정 목록 자체는 앱 화면에 노출하지 않음 — 맥락 인식에만 활용
② 미팅 전 버퍼 감지
•  '30분 뒤 미팅이 있어요 — 지금 시작하면 한 세션 완료할 수 있어요'
•  남은 시간에 맞는 세션 길이 자동 제안 (30분 → 25분, 15분 → 10분)
